# Overview produce models

The Overview scene uses these local GLB assets:

- `red-onion.glb` — Red Onion, Food, Fresh Produce and Groceries
- `beef-tomato.glb` — Beef Tomato, Food, Fresh Produce and Groceries

Both models are from [3DAssets.dev](https://3dassets.dev/packs/fresh-produce-and-groceries)
and are released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
The files are stored locally so the scene does not depend on a remote asset server.
