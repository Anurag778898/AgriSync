# Original produce models

These original GLB files are retained here as source files:

- `red-onion.original.glb` — Red Onion
- `beef-tomato.original.glb` — Beef Tomato

Both models are from [3DAssets.dev](https://3dassets.dev/packs/fresh-produce-and-groceries)
and are released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
These source models remain available for future use. The current Overview artwork is an inline SVG and does not load either file.
